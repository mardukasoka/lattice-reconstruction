# LRA Media Licensing Policy

LRA uses evidence-bearing visual assets only when their reuse status is recorded.

## Asset priority

1. CC0 / public domain
2. CC BY
3. CC BY-SA
4. Authoritative external museum or archive link
5. Evidence-constrained generated reconstruction, explicitly labelled RECONSTRUCTED or HYPOTHETICAL

Do not copy a museum-hosted photograph merely because the underlying ancient object is in the public domain. Copyright in the photograph and the object are tracked separately.

## Required metadata

Each admitted visual asset should record:

- object or location identifier
- creator / photographer
- source page
- licence and licence version
- attribution text
- commercial-use status
- modification status
- embed status: EMBED_OK or LINK_ONLY
- relationship to the historical object: exact object, reconstruction, representative object, or contextual image
