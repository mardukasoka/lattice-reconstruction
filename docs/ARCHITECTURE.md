# Reconstruction architecture

This repository is the experimental reconstruction shell. It does not replace Chess Atlas, the factual Atlas, or the Archaic Web archive.

Inform 7 knows what the player has discovered. The Web displays the shell, local terminal time, diagrams and later browser-interpreter output. The Atlas remains authoritative for evidence and provenance. Humans decide meaning. The Lattice remains an optional fiction layer; the software does not assert its ontology.

## First world

Recovery Console → Orientation, with Orientation connecting to Reconstruction Gallery, Archive and Terminal.

The six memory housings are intact sequences with unresolved origin and chronology. The shell deliberately does not interpret them.

## Temporal offset

+00:02:00 is a narrative processing coordinate. It is not a prediction engine and must never become artificial latency or a claim of foreknowledge.

## Gallery

Gallery entries have explicit epistemic class and provenance. External diagrams must not be copied until rights and attribution are verified. Prefer original diagrams generated from our own data.

## Browser integration

v0.1 contains no copied Vorple code and no compiled Inform runtime. mardukasoka/inform7 is a reference fork of vorple/inform7. Current Inform/Quixe/Vorple compatibility and licensing must be audited before incorporation.
