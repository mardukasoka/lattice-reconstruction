# Lattice Reconstruction

Experimental Inform 7 reconstruction environment and diagram gallery, deliberately separate from Chess Atlas.

## v0.1

**Recovery Console → Orientation → Reconstruction Gallery / Archive / Terminal**

Inform source: `inform/Reconstruction.inform/Source/story.ni`.

The lightweight `web/` shell demonstrates device-local terminal orientation and a provenance-aware gallery. It does not claim that the Inform story has been compiled for the browser yet.

**Preserve. Observe. Record.**

The system has no authority to manufacture the history it preserves. The `+00:02:00` offset is a narrative processing coordinate, not prediction or foreknowledge.

See `docs/ARCHITECTURE.md` and `docs/OPEN_SOURCE.md`.
